# Bambu 看板（Bambu Lab A1）

给拓竹 A1 做的本地看板：电脑上开一个窗口，平板/手机扫二维码也能看同一个界面。

- **电脑端**：tkinter 窗口 —— 看板 / 层图 / 打印历史 / 事件流水 / 控制 / 打印机存储 / 全部字段
- **网页端**：同一个程序顺带开的网页（`0.0.0.0:8787`），手机、平板直接看
- 打印状态、温度曲线、摄像头画面、层图、事件流水、弹窗提示、仪表盘

## 它连打印机的四种方式

| 接口 | 端口 | 用途 |
|---|---|---|
| MQTT over TLS | 8883 | 状态、温度、进度（用户名 `bblp`，密码 = 打印机访问码） |
| 摄像头 | 6000 | 画面（TLS + 64 字节认证包，之后每帧 16 字节头 + JPEG） |
| FTPS（隐式 TLS） | 990 | `/timelapse`、`/cache` 里的 3mf、打印历史 |
| HTTP 看板 | 8787 | 自己开的网页，给平板/手机 |

踩过的坑：

- **必须用具体 topic**（`device/<序列号>/report`）。用 `#` 通配符订阅会被打印机拒绝，一条消息都收不到。
- **MQTT 只能 QoS 0**。用 QoS 1 打印机会把会话直接踢掉，连开灯都不好使。
- 打印机的访问码可以从 Bambu Studio 的配置里读（不是严格 JSON，得用正则）。

## 访问码（网页门禁）

网页本身不带密码，所以代码里加了一层：

- 访问码存在**桌面**的 `Bambu看板访问码.txt`（第一次运行自动生成一个 6 位数字）
- **改那个文件立刻生效**，不用重启程序（每次请求都重读）
- 没输访问码时，所有 `/api/*` 返回 **401**，页面只弹一个输入框
- **访问码不在前端**，校验在 Python 后端；登录成功后发一个 cookie（30 天）

## 运行

```bash
pip install paho-mqtt pillow zeroconf
python bambu_dash.py
```

配置文件 `bambu_dash.json`（`ip` / `serial`）第一次运行会自己建。

打包成单文件 exe：

```bash
pyinstaller --onefile --noconsole --name BambuDash bambu_dash.py
```

配置、日志、截图都跟着程序所在目录走（打包后就是 exe 旁边）。

## 已知限制

- **改不了喷头坐标**：A1 固件要签名（ACS），第三方客户端发不了移动指令；暂停 / 停止 / 调速也一样被拒（`HMS_0500-0500-0001-0007`）。实测只有**灯**能控。
- **拿不到喷头坐标**：MQTT 上报里没有 X/Y/Z。所以「红点画在盘子上的哪儿」是靠摄像头找喷头贴纸 + 找盘子前沿**估算**出来的，贴纸比喷嘴高几厘米，有视差，只能当参考。
- 摄像头约 **0.46 帧/秒**，这是 A1 本身的限制。
